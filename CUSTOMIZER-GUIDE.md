# 📸 راهنمای تصویری

## مسیر Customizer:

```
WordPress Dashboard
    ↓
Appearance
    ↓
Customize
    ↓
[تنظیمات Header]  ← اینجا!
[تنظیمات Footer]  ← اینجا!
```

## نحوه استفاده:

### 1. کلیک روی "تنظیمات Header"
```
👆 کلیک
```

### 2. انتخاب نوع
```
پیش‌فرض ▼
    ↓
[با دکمه CTA] ← انتخاب
```

### 3. تغییر رنگ
```
#ffffff ← کلیک
    ↓
انتخاب رنگ جدید
```

### 4. Publish
```
[Publish] ← کلیک
```

---

## مثال عملی:

```
قدم 1: Customize باز کن
قدم 2: "تنظیمات Header" کلیک
قدم 3: نوع Header → "با دکمه CTA"
قدم 4: رنگ → #3C50E0
قدم 5: Publish کلیک
قدم 6: سایت رو ببین! ✅
```
